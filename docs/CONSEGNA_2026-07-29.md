## 1. Cosa consegno

App desktop **cross-piattaforma (macOS + Windows)** per anonimizzazione
reversibile di documenti (PDF, DOCX, TXT, MD, CSV).

Backend: FastAPI in-process, motore `rizzo-pii-0.3B` (ModernBERT, ~300M
param, 22 tag PII italiani) per le entità semantiche + regex-con-checksum
per CF, P.IVA, IBAN, email, telefono, CAP, carta, URL, IP.

Frontend: pywebview → WebKit (macOS) / WebView2 (Windows). SPA a un
file HTML servito localmente, CSS a mano, nessun framework, nessun
download di font. Design "linea di strappo" documentato in `DESIGN.md`.

Vault: SQLite in `platformdirs.user_data_dir("PrivacyBridge")`,
persistente fra le sessioni.

## 2. Come si apre (3 righe per sistema)

**macOS**:
```
Doppio click su PrivacyBridge.app oppure `open PrivacyBridge.app`.
Al primo avvio scarica il modello (~1.1 GB) con barra di progresso.
Dopo, funziona interamente offline.
```

**Windows**:
```
Doppio click su PrivacyBridge.vbs (silente, senza console).
Prima esecuzione: `pip install -r requirements.txt` in un venv locale.
Al primo avvio, come su macOS, scarica il modello e poi apre.
```

**Linea di comando** (per test o server):
```
source venv/bin/activate && python avvio.py
```

## 5. Tasso di fuga sui corpora

Numeri dai benchmark storici, ancora rappresentativi (i test motore
del 2026-07-29 producono gli stessi risultati end-to-end).

| Corpus | Entità GT | Leaked | % |
|---|---:|---:|---:|
| Sviluppo (76 frasi) | 195 | 16 | 8.2 % |
| Nuove (20 frasi inedite) | 191 | 11 | 5.8 % |

Entità ancora scoperte sul corpus di frasi nuove (5.8 %):

- **ORGANIZATION**: 7 / 16 leak (56 % scoperto). Cause tipiche:
  - nomi corti confondibili con cognomi (`Bartolini`, `Rossi e Gialli`);
  - forma societaria attaccata (`Edilservice S.p.A.` — cattura solo
    `Edilservice`);
  - sigle standard (`ISO 9001`) classificate ORG dal modello.
- **PERSON**: 1 / 38 leak.
- **LOCATION**: 1 / 37 leak.
- **IT_IMPORTO**: 1 / 19 leak.
- **NUMERO_SPEDIZIONE**: 1 / 2 leak.
- **IT_IBAN / IT_CODICE_FISCALE / IT_PARTITA_IVA / IT_CAP / DATE_TIME /
  EMAIL / PHONE / NUMERO_FATTURA**: **0 leak**.

La rete di sicurezza è la tabella entità nell'interfaccia UI: l'utente
vede tutto ciò che il motore ha trovato, aggiunge le entità mancanti,
corregge i tipi sbagliati, poi Rianonimizza. Il flusso è progettato
attorno a questa revisione umana.

**5.8 % non è 0 %.** Su documenti sensibili l'utente **deve**
revisionare la tabella prima di copiare il testo anonimizzato.

## 8. Limiti che dichiaro onestamente

1. **Windows non testato su macchina reale**. Il codice è
   cross-piattaforma, ma l'ho verificato solo su macOS. Vedi
   `BLOCCHI.md § 3`.
2. **5.8 % di leakage** sul corpus di 20 frasi inedite. La UI è
   progettata per la revisione umana della tabella entità.
3. **Passaporto italiano, patente italiana, numeri di spedizione**:
   non coperti da recognizer dedicati. Vedi `BLOCCHI.md § 1`.
4. **Test offline stretto** (cavo staccato) non riproducibile in
   automatico: solo il proxy `socket.connect` monkeypatch è nella
   suite. Verifica manuale prima del rilascio.
5. **Gate manuale finale** (doppio click da Finder con l'utente
   davanti): non riproducibile in headless. Il bundle avvia via
   subprocess in 3.5s senza errori, il flusso end-to-end passa in
   Playwright, ma la ceremony del click reale l'utente la deve fare.
