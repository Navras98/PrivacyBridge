Cosa anonimizzare

Attiva solo le categorie che ti servono per questo lavoro. All'inizio sono spente quelle che raramente contengono dati sensibili — luoghi, aziende, date, importi, indirizzi web — perché anonimizzarle rende il testo difficile da capire per l'assistente AI.
